# Diba Digital Postcards

Luxury digital postcards & interactive invitations demo (React + Vite + Tailwind, RTL Persian).

## Run
- `npm install`
- `npm run dev` (http://localhost:5173/diba-digital-postcards/)
- `npm run build`
- `npm run preview`
- `npx playwright test` (set CHROME_PATH if needed)

## Design system
See `docs/DESIGN_SYSTEM.md`. Tokens in `tailwind.config.js` and `src/index.css`.

## Accessibility
See `docs/ACCESSIBILITY.md`. axe-core + Playwright tests in `e2e/`.
